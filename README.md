# Portfolio Website

A clean, modern and responsive personal portfolio website designed to showcase my skills, projects and services as a UI/UX Designer.

## ✨ Features
- Responsive design for mobile, tablet and desktop
- Home, About, Services, Portfolio and Contact sections
- Modern gallery and project showcase
- Clean layout with smooth user experience
- Easy to customize

## 🛠️ Built With
- HTML5
- CSS3
- Responsive Design

## 📂 Project Structure
- `index.html` - Main homepage
- `gallery1.jpg` - `gallery6.jpg` - Project images
- `README.md` - Project documentation

## 🚀 How To View
1. Download / Clone this repository
2. Open `index.html` in any browser
3. No installation needed
